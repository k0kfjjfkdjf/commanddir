# >_ CommandDir

Офлайн-шпаргалка по командной строке **Linux, macOS и Windows** (cmd и PowerShell) для телефона.

**Открыть:** https://k0kfjjfkdjf.github.io/commanddir/ → в меню браузера «Установить приложение» / «На экран „Домой“».
**Android APK:** вкладка [Releases](../../releases) или артефакт последней сборки в [Actions](../../actions/workflows/android.yml).

## Что внутри

| Раздел | Содержимое |
|---|---|
| **Команды** | ~200 команд: синтаксис, подробное описание, таблица ключей, примеры с кнопкой «копировать», предупреждения, отличия GNU/BSD, аналоги в других ОС, связанные команды |
| **Конструкции** | Потоки и коды возврата, `\|`, `>`/`2>&1`, here-doc, `&&`/`\|\|`, if/case/for/while, переменные и `${…}`, `$(…)`, glob, кавычки, регулярки, скрипты и `set -euo pipefail`, trap, сигналы; bat-файлы и `for /f`; объектный конвейер и операторы PowerShell — со сравнением синтаксиса между оболочками |
| **Рецепты** | Готовые связки с пошаговым разбором: что заняло диск, кто держит порт, топ IP в логе, бэкап rsync, SSH-ключи, запись ISO, починка Windows и др. |
| **Разбор** | Вставьте любую строку — приложение разобьёт её на команды, ключи, конвейеры и перенаправления и объяснит каждую часть |
| **Избранное** | Свои закладки (хранятся на устройстве) |

Фильтр по ОС, поиск по-русски («порт», «удалить», «архив») и по ключам, тёмная/светлая тема, работа без интернета.

## Устройство

Чистые HTML/CSS/JS без сборки и зависимостей (`www/`), Service Worker для офлайна. Контент лежит в `www/data/*.js` — добавить команду = добавить объект:

```js
C({ id: 'ls', n: 'ls', os: 'lm', c: 'nav', s: 'Список файлов',
   syn: 'ls [опции] [путь]', d: 'Описание…',
   o: [['-l', 'Длинный формат']], e: [['ls -lah', 'Пояснение']],
   eq: { w: 'dir, Get-ChildItem' }, r: ['cd', 'find'] });
```

`os`: `l` Linux, `m` macOS, `w` Windows · `sh`: `cmd` / `ps` для Windows · `r` — связанные id · `w` — предупреждение · `nt` — нюансы.

```bash
npm run serve    # http://localhost:8080
npm run check    # проверка данных и перекрёстных ссылок
```

## Сборка

- **GitHub Pages** — `.github/workflows/pages.yml` при каждом пуше в `main` (Settings → Pages → Source: *GitHub Actions*).
- **Android APK** — `.github/workflows/android.yml` оборачивает `www/` в Capacitor и собирает APK. Тег `v*` (`git tag v1.0.0 && git push --tags`) публикует APK в Releases.
- **iPhone** — через Safari: «Поделиться → На экран „Домой“».
